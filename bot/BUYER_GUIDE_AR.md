# دليل استخدام البوت للمشتري / مالك البوت

## فكرة البوت

البوت متجر رقمي متكامل داخل تيليجرام، يدعم الأقسام والمنتجات والمزودين وسوق المستخدمين والإعلانات والعروض والشحن والسحب.

## القنوات

- `ADMIN_NOTIFY_CHAT_ID`: قناة خاصة للأدمن، تصلها الإيصالات، طلبات السحب، مراجعات السوق، الأخطاء، النزاعات.
- `PUBLIC_CHANNEL_ID`: قناة عامة للتسويق، تصلها عمليات الشراء الناجحة والإعلانات والعروض ومبيعات السوق الناجحة.

## لوحة الأدمن

### 📘 شرح البوت
شرح داخلي لكل زر وخدمة وطريقة ربط المزودين وإضافة المنتجات.

### 📂 إدارة الأقسام
الأقسام الرئيسية والفرعية. يمكنك تعديل الاسم، الإيموجي، الترتيب، التفعيل، وإضافة أقسام فرعية ومنتجات.

### 🎛 أزرار الواجهة
إنشاء أزرار رئيسية تربط إلى قسم، قسم فرعي، منتج، صفحة داخلية أو رابط خارجي. يوجد فحص للأزرار المكسورة.

### 🔌 مزودو المتجر
ربط مزودي API للرشق، الألعاب، التطبيقات، الأرصدة، البطاقات، الاشتراكات، الأكواد أو أي متجر عام.

#### ربط مزود بدون كود
1. مزودو المتجر ← إضافة مزود.
2. اختر Custom JSON.
3. اختر معالج ربط بدون JSON.
4. أدخل مسار المنتجات وحقول id/name/price/category.
5. أدخل مسار الطلب والحالة.
6. احفظ واختبر الاتصال.
7. زامن الخدمات.
8. حول خدمة المزود إلى منتج.

### 📦 إدارة المنتجات
كل منتج يكون واحداً من:

- API: ينفذ تلقائياً عبر مزود.
- Inventory: كود/حساب/بطاقة مخزنة مشفرة وتسلم فوراً.
- Manual: يشتريه المستخدم وينفذه الأدمن يدوياً.

استخدم زر فحص جاهزية المنتج قبل البيع.

### 🏪 سوق المستخدمين
منصة بيع بين المستخدمين بضمان البوت. الأكواد والحسابات تحفظ مشفرة. المشتري يؤكد الصحة أو يفتح نزاعاً.

### 📢 إدارة الإعلانات
إعلانات مدفوعة بـ2$، يراجعها الأدمن، تنشر داخل البوت والقناة العامة، وتجدد بـ1$.

### 🔥 قسم العروض
عروض 24 ساعة يدوية أو تلقائية عبر مزود، مع تذكيرات وتصويت تمديد.

### 💳 الشحن و 💸 السحب
يدعم شام كاش، USDT، نجوم تيليجرام، وطرق أخرى. السحب يراجع يدوياً من الأدمن.

### 👥 إدارة المستخدمين
عرض عدد المستخدمين، قائمة المستخدمين، البحث بالآيدي، إضافة/خصم رصيد، إرسال رسالة، حظر/فك حظر.

### 📌 الاشتراك الإجباري
إضافة عدد غير محدود من القنوات. يجب أن يكون البوت أدمن في كل قناة.

### 📢 إذاعة جماعية
إرسال نص/صورة/فيديو/ملف لكل المستخدمين غير المحظورين.

## واجهة المستخدم

- الأقسام الرئيسية: الرشق، الألعاب، التطبيقات، الأرصدة، البطاقات، الاشتراكات، التوثيق، الأكواد.
- شحن الرصيد: إضافة رصيد.
- سحب الرصيد: طلب سحب الأرباح.
- سوق المستخدمين: بيع وشراء بضمان.
- العروض الخاصة 24: عروض محدودة الوقت.
- إعلاناتي: نشر إعلان مدفوع.
- الإشعارات: صندوق وارد لكل الرسائل المهمة.
- معلومات البوت: شرح للمستخدم وحقوق المبرمج.
