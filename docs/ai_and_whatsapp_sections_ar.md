# القسمان الرئيسيان: الذكاء الاصطناعي + واتساب — دليل الأدمن

## 🤖 القسم الأول: الذكاء الاصطناعي

زر جديد في القائمة الرئيسية: **«🤖 الذكاء الاصطناعي»** — لا يظهر إطلاقاً
قبل ضبط مفتاح NanoGPT (حماية من عرض قسم لا يعمل).

### الأقسام الجاهزة (تُزرع تلقائياً أول تشغيل)
| القسم | النوع | ماذا يفعل |
|---|---|---|
| 👨‍💻 برمجة بدون قيود | code | المستخدم يطلب كوداً/أداة/ملفاً كاملاً → النتيجة توصله **ملفاً جاهزاً للتحميل** (لأن تيليجرام يقصّ الرسائل الطويلة) |
| 💬 تحدث بدون قيود | chat | دردشة حرة، الموديل يتذكر سياق الجلسة الحالية |

كلاهما قابل للتعديل من اللوحة (الموديل، الشرح، الأسعار، System Prompt،
تفعيل/إيقاف/حذف) — والقسمان **مخفيان عن المستخدمين حتى تضبط مفتاح NanoGPT**.

### ⚙️ الإعداد (مرة واحدة — دقيقتان)
1. لوحة الأدمن ← **⚙️ النظام والعمليات** ← **🤖 أقسام الذكاء الاصطناعي**.
2. **🔑 مفتاح NanoGPT** ← الصق مفتاحك من `nano-gpt.com/api` — يُختبر فوراً.
3. افتح كل قسم وعدّل الموديل والأسعار حسب رغبتك، وتأكد أنه مفعّل 🟢.
4. خلص — الزر ظهر في القائمة الرئيسية لكل المستخدمين.

### ➕ إضافة قسم ثالث (وأي قسم مستقبلي)
**➕ قسم جديد** ← معالج 9 خطوات:
العنوان ← الإيموجي ← **الشرح (تكتبه يدوياً: مهمة القسم وماذا يفعل)** ←
النوع (برمجة = رد كملف / دردشة = نصي / مخصص = نصي لأي فكرة) ←
**الموديل من NanoGPT** (مثل `openai/gpt-5.2` أو `z-ai/glm-4.6`) ←
System Prompt ← طريقة التسعير ← التكلفة التقريبية ← مضاعف الربح.

### 💰 التسعير — كيف يُخصم الرصيد بالضبط
لكل قسم طريقتان:

1. **حسب استهلاك المزود × مضاعف (الموصى بها — وهي الافتراضية):**
   - NanoGPT يرجع **التكلفة الفعلية بالدولار مع كل رد**.
   - الخصم = التكلفة الفعلية × **مضاعف الربح** (افتراضي **3** = ربح 3 أضعاف).
   - قبل الإرسال يُخصم المبلغ التقريبي حجزاً، وبعد الرد تُسوّى تلقائياً:
     زيادة تُخصم، نقص **يُرجع لرصيد المستخدم**. الدفاتر دقيقة دائماً.
   - لأن السياق يكبر مع الجلسة، الرسائل المتأخرة أكلف من الأولى — والنظام
     يحسبها تلقائياً من تكلفة المزود الفعلية، فلا تخسر أبداً.
2. **سعر ثابت:** مبلغ محدد لكل رسالة بغض النظر عن الاستهلاك.

كل حركة تُسجَّل في دفتر الحركات (`transactions`) بنوع
`ai_usage` / `ai_usage_adjust`، ورسالة الحجز الفاشلة **تُرجع كاملة**.

### 🗂 الجلسات
- كل محادثة = جلسة باسم أول رسالة، وكل رسالة تُحفظ (نص، تكلفة المزود،
  المُحصّل، التوكنز) في `ai_sessions` / `ai_messages`.
- المستخدم: **🗂 جلساتي** ← يفتح أي جلسة، يشوف رسائلها، ويتابعها من حيث توقف.
- الأدمن: **🧾 جلسات المستخدمين** ← يكتب آيدي المستخدم ← كل جلساته ورسائلها.

### 🧠 اختيار الموديل من NanoGPT
الأسماء بصيغة `provider/model` — تعرضها `nano-gpt.com/models` مع سعر كل
موديل (لا توجد علامة على الأسعار، والتكلفة الفعلية تعود في كل استجابة).
أمثلة اقتصادية للدردشة: `z-ai/glm-4.6`، `minimax/minimax-m2.7`.
للبرمجة الثقيلة: `openai/gpt-5.2`، `anthropic/claude-sonnet-4.6`.

## 📱 القسم الثاني: واتساب (مربوط بالبوت الثاني)

زر جديد في القائمة الرئيسية: **«📱 واتساب»** — يظهر فقط بعد تفعيل القسم
من اللوحة.

### الفكرة
هذا البوت لا يتكلم مع واتساب مباشرة — يتكلم مع **سيرفر جسر** تديره أنت
بجانب بوتك الثاني (الذي يربط جلسات واتساب). من داخل هذا البوت:
- المستخدم يشترك **بـ 1$ يومياً** (سعر قابل للتعديل) من رصيده.
- يرسل رقمه ← يستلم **كود اقتران** ← يدخله في واتساب (الأجهزة المرتبطة ←
  ربط جهاز ← ربط برقم الهاتف).
- بعد الربط تظهر **أزرار بوتك الثاني داخل هذا البوت**، وكل ضغطة تُمرر
  للجسر ويرجع الرد — أي أن كل أوامر البوت الثاني تعمل من هنا.

### ⚙️ الإعداد
1. على سيرفر البوت الثاني: شغّل التنفيذ المرجعي
   `scripts/wa_bridge_reference_server.py` واربط منطق جلساتك بداخله
   (نقاط الدمج معلّمة `TODO(البوت الثاني)`). العقد كامل في
   `docs/whatsapp_bridge_v1_ar.md` — 5 مسارات فقط.
2. لوحة الأدمن ← **🤖 أقسام الذكاء الاصطناعي** ← **📱 قسم واتساب**:
   - 🌐 رابط سيرفر الجسر + 🔑 مفتاح الجسر
   - 💵 سعر اليوم (افتراضي 1.00$)
   - 📝 **وصف القسم** (اكتبه يدوياً — يظهر للمستخدمين في شاشة القسم)
   - 🤖 يوزر البوت الثاني (رابط احتياطي يفتح البوت مباشرة)
   - 🟢 فعّل القسم ← **🧪 اختبار الاتصال**
3. زر «📱 واتساب» ظهر في القائمة الرئيسية.

### 🔐 الاشتراك اليومي
- الدفع من الرصيد بنوع حركة `wa_subscription`، والتمديد يُكدّس فوق
  المتبقي (اشتراكان = يومان).
- كل شيء يتفقد الاشتراك قبل الربط/القائمة/الحالة — انتهى اليوم = يعود
  لشاشة الاشتراك تلقائياً.
- المشتركون ومدفوعاتهم في `whatsapp_subscriptions`، ومراجعتهم من اللوحة
  (👥 المشتركون).
