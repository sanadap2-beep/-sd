# عقد جسر واتساب — الإصدار 1 (WhatsApp Bridge API v1)

هذا العقد يشرح كيف يتحدث **البوت الرئيسي** (بوت المتجر) مع **البوت الثاني**
(بوت جلسات واتساب). البوت الرئيسي لا يتصل بواتساب أبداً — كل شيء يمر عبر
سيرفر الجسر الذي يشغّله/يستضيفه البوت الثاني.

التنفيذ المرجعي الكامل جاهز هنا:
`scripts/wa_bridge_reference_server.py` (FastAPI) — شغّله بجانب البوت الثاني
وصّل دواله بمنطق الجلسات عندك (Baileys / whatsapp-web.js / أي محرك)، وسنشتغل
القائمة كاملة داخل البوت الرئيسي.

---

## الإعدادات في لوحة البوت الرئيسي

| الإعداد | المكان | الوصف |
|---|---|---|
| `wa_bridge_enabled` | لوحة الأدمن ← 🤖 الذكاء الاصطناعي ← 📱 قسم واتساب | تفعيل/تعطيل القسم بالكامل |
| `wa_bridge_base_url` | نفس الشاشة | رابط سيرفر الجسر، مثال `https://wa.example.com` |
| `wa_bridge_api_key` | نفس الشاشة | مفتاح سري يُرسل في ترويسة كل طلب |
| `wa_daily_price` | نفس الشاشة | سعر اليوم الواحد بالدولار (افتراضي 1.00) |
| `wa_description` | نفس الشاشة | وصف القسم الذي يظهر للمستخدمين |
| `wa_bot_username` | نفس الشاشة | (اختياري) يوزر البوت الثاني — يظهر كرابط احتياطي |

## المصادقة

كل الطلبات من البوت الرئيسي تتضمن ترويسة:

```
X-Bridge-Key: <wa_bridge_api_key>
```

إذا المفتاح خاطئ أعد `401`.

## المسارات (Endpoints)

### 1) `GET /health`
فحص سريع من لوحة الأدمن (زر 🧪 اختبار الاتصال).

```json
{ "ok": true, "engine": "baileys", "active_sessions": 12 }
```

### 2) `POST /sessions`
المستخدم أرسل رقم واتساب — أنشئ جلسة وأعطني كود اقتران.

```json
// الطلب
{ "phone": "+963955123456" }

// الرد 200
{
  "session_id": "sess_a1b2c3",      // معرف فتحتَه أنت — سنستخدمه بكل الطلبات القادمة
  "status": "pending",
  "pairing_code": "ABCD-1234",      // يُعرض للمستخدم فوراً
  "expires_in": 120                  // ثوانٍ حتى انتهاء الكود (اختياري)
}
```

- الجسر يعرض كود الاقتران على محرك واتساب عنده (pairing code) لحظة الإنشاء.
- إذا كان للرقم جلسة قائمة: أعدها أو أنشئ جديدة وحرر القديمة — قرارك.

### 3) `GET /sessions/{session_id}`
فحص حالة الجلسة (يستخدمه زر «🔌 حالة الاتصال» وقبل عرض القائمة).

```json
{ "session_id": "sess_a1b2c3", "phone": "+963955123456", "status": "linked" }
```

القيم المقبولة لـ `status`:

| القيمة | المعنى عند البوت الرئيسي |
|---|---|
| `pending` | بانتظار إدخال كود الاقتران |
| `linked` أو `connected` | مربوطة وتعمل — تظهر الأزرار |
| `expired` | انتهت صلاحية الكود — المستخدم يطلب كوداً جديداً |
| `disconnected` أو `logged_out` | فُصلت — يحتاج إعادة ربط |

### 4) `POST /sessions/{session_id}/command`
المستخدم ضغط زراً من أزرار البوت الثاني داخل البوت الرئيسي — نفّذ الأمر
وأرجع النتيجة + القائمة الجديدة.

```json
// الطلب
{ "action": "menu" }                  // أو أي action أرجعته أنت سابقاً مثل "buy:netflix"
{ "action": "text", "text": "..." }   // إذا أردت استقبال نص حر من المستخدم (اختياري)

// الرد 200
{
  "text": "قائمة الأوامر:\n1. شراء اشتراك …",
  "buttons": [
    { "text": "🛒 شراء اشتراك", "action": "buy" },
    { "text": "📊 حسابي", "action": "account" },
    { "text": "🔙 الرئيسية", "action": "menu" }
  ]
}
```

- `buttons` اختيارية — إن لم ترجعها تختفي الأزرار ويبقى نص النتيجة فقط.
- `action` نص حر من عندك: تعيده أنت في كل قائمة وتستقبله عند الضغط.
- الحد: 32 زراً في القائمة الواحدة، وكل نص يُقص عند 3500 حرف.
- مهلة انتظار البوت الرئيسي: 60 ثانية.

### 5) `DELETE /sessions/{session_id}`
المستخدم ضغط «🔓 فصل الرقم» — أنهِ جلسة واتساب عندك.

```json
{ "ok": true }
```

## تدفق المستخدم الكامل (مثال واقعي)

1. المستخدم يفتح «📱 واتساب» ← يشترك بـ $1 من رصيده (يُخصم تلقائياً).
2. يرسل رقمه `+963955123456`.
3. البوت الرئيسي → `POST /sessions` → يعرض الكود `ABCD-1234` مع خطوات الإدخال
   (واتساب ← الأجهزة المرتبطة ← ربط جهاز ← ربط برقم الهاتف).
4. المستخدم يضغط «🔄 فحص الحالة» → `GET /sessions/...` → `linked` ✅.
5. يضغط «🧭 أوامر واتساب» → `POST .../command {"action":"menu"}` → تظهر أزرار
   بوتك الثاني **داخل البوت الرئيسي**.
6. كل ضغطة زر تُمرر كـ `action` إلى الجسر ويرد البوت الرئيسي بنص القائمة
   الجديدة وأزرارها — وهكذا «كل أوامر البوت الثاني تعمل من هنا».

## ملاحظات أمان

- شغّل الجسر خلف HTTPS فقط، واجعل المفتاح طويلاً وعشوائياً.
- القيم كلها تمر عبر لوحة الأدمن وتُحفظ في جدول `settings` — لا توضع في Git.
- البوت الرئيسي يخزّن فقط: الرقم، `session_id`، الكود، الحالة، وآخر قائمة أزرار.
