# من أين تشحن مواقع وبوتات الألعاب السورية؟ — قرار عملي مبني على أدلة علنية

**تاريخ الرصد:** 30-10-2026

**النطاق:** شحن الألعاب المباشر بالـUID/Player ID، وخصوصاً PUBG Mobile وFree Fire وMobile Legends.

**الغرض:** اختيار مورد لبوت/موقع سوري، لا تسمية متجر تجزئة على أنه مورد خلفي بلا دليل.

> ## الجواب المباشر
>
> - لا يوجد دليل علني يثبت أن كل المواقع والبوتات السورية تعتمد مزوداً واحداً مسمى.
> - **إن كان المطلوب مورداً سورياً محلياً لبوت/موقع:** فإن **MaxStore** هو أفضل مرشح ظاهر علناً، لأنه الوحيد في الرصد الذي يعلن صراحةً **REST API لإعادة البيع**، مع بوت Telegram وكتالوج كبير وتنفيذ آلي ودفع سوري محلي. لكن مصدره الأعلى وأسعار الـreseller وشروط الـAPI ليست منشورة، لذلك لا يثبت أنه الأرخص أو أن مواقع سورية أخرى تستخدمه.
> - **إن كان المطلوب أرخص مصدر تقني فعلي للبوت:** لا تشترِ من متاجر التجزئة السورية. استخدم **FazerCards** مباشرةً كمورد أول (التكامل موجود في هذا المشروع)، وابقِ **WDGZone** للمقارنة/البديل. أسعارهما أقرب كثيراً إلى بصمة أسعار المتاجر السورية من أسعار البيع المحلية.
> - **SGC GAME** ليس مورداً مثبتاً، لكنه أقوى مؤشر سعري: بعض أسعاره تتطابق تقريباً مع سعر FazerCards الذي ظهر في لوحة حساب المشروع مضافاً إليه نحو 3%. هذا يرجح أنه يستخدم FazerCards مباشرة أو مصدراً أعلى مشتركاً معه؛ **لا يثبت أيّاً منهما**.

## 1) لا تخلط بين «واجهة سورية» و«مورد الشحن الفعلي»

المتاجر السورية الظاهرة تحقق غالباً ثلاثة أدوار مختلفة:

1. تستقبل الدفع المحلي، مثل شام كاش وسيريتل كاش.
2. تعرض الطلب للعميل وتجمع الـUID/Player ID.
3. تمرر طلب الشحن إلى مزود أعلى غير معلن.

وجود متجر سوري سريع لا يعني أنه مصدر مخزون الشحن نفسه. مثلاً، [GameStoreSY](https://gamestoresy.com/terms-of-use/) يصف نفسه علناً كوسيط بين العميل و«مزودي بطاقات الألعاب» من دون تسمية هؤلاء المزودين. كما تؤكد [سياسة خصوصية MaxStore](https://www.maxstore1.com/privacy) أن بيانات التنفيذ مثل Player ID أو رابط الحساب تُرسل إلى «مزودي المنتجات»، لكنها لا تكشف أسماءهم.

**النتيجة:** يمكننا ترتيب المرشحين، لكن لا يجوز الجزم باسم المورد الخلفي لأي متجر ما لم ينشره أو يعطي وثيقة رسمية قابلة للتحقق.

### قرار MaxStore

إذا كانت الأولوية هي **الدفع السوري والتعامل مع مزود محلي**، ابدأ به كأول جهة اتصال. لا تعامله كمورد نهائي قبل أن يرسل، كتابياً:

- رابط توثيق API أو OpenAPI؛
- كتالوج reseller وأسعار شراء لعينة PUBG/Free Fire/MLBB؛
- حقول كل لعبة (UID وZone/Server عند الحاجة)؛
- حالات الطلب وwebhook أو endpoint للاستعلام؛
- سياسة الطلب الفاشل والاسترجاع؛
- حد الإيداع ومدة تنفيذ قابلة للقياس.

إذا لم تتوفر هذه الستة، فـMaxStore ليس مناسباً لربط بوت آلي مهما بدا كتالوجه كبيراً.

## 3) ما الذي تكشفه الأسعار السورية عن المصدر المحتمل؟

في اللقطة المرصودة، تقارب أسعار Free Fire MENA المعلنة منه بشكل غير عشوائي مع الأسعار الفعلية التي ظهرت في لوحة FazerCards الخاصة بالمشروع:

**الاستنتاج الصحيح:**

- الفارق المتكرر قرب 3% هو **بصمة قوية** على أن SGC يستخدم FazerCards أو قناة أعلى تشترك معه في قائمة سعر قريبة جداً.
- لا يكفي ذلك لإثبات علاقة تعاقدية مباشرة: قد تكون لديه قناة/خطة أخرى أو مصدر مشترك، وقد تكون المنطقة أو المنتج الفعلي مختلفاً في بعض الباقات.
- لذلك لا تأخذ SGC كمورد للربط؛ خذه كسقف منافسة محلي. إذا ظل سعر FazerCards لديك قريباً من الجدول بعد كل رسومك، تستطيع المنافسة بهامش صغير بدلاً من شراء الخدمة من SGC ثم إضافة هامشك فوقه.

رابطا صفحات الأسعار المرجعية: [PUBG Global](https://sgc-game.com/game/pubg-mobile-uc-global) و[Free Fire MENA](https://sgc-game.com/game/free-fire-mena).

### S7SH: متجر تجزئة، لا B2B مثبت

[S7SH](https://s7sh.com/) يعلن شحناً تلقائياً بالـID و«أسعار جملة»، لكن لا يتيح توثيق API أو كتالوج reseller أو هوية المورد. في لقطات الرصد كان 60 UC بـ$1.00 و110 Free Fire Diamonds بنحو $1.04–$1.05، فوق تكلفة FazerCards المرصودة بنحو 14% تقريباً. هذا سلوك سعر تجزئة طبيعي، لا دليل على أنه مورد لبوتات أخرى.

روابط الرصد: [60 UC PUBG](https://s7sh.com/services/60-uc-pubg) و[110 Free Fire Diamonds](https://s7sh.com/services/110-free-fire-jewel).

### Dark Shot: جهة تواصل محتملة فقط

[Dark Shot Store](https://darkshotstore.com/) يعلن أسعار جملة لأصحاب المتاجر، وإيداعاً تلقائياً، وتظهر فيه فئة باسم `Test API`. لكن لا توجد وثائق API علنية أو endpoint أو نموذج حالات الطلب أو شروط reseller قابلة للفحص. لذلك يصنف كـ**مرشح للتواصل التجاري**، وليس مورداً تقنياً يربط به البوت حالياً.

## 4) ترتيب القرار للبوت/الموقع الحالي

| الترتيب | الخيار | ماذا تستخدمه له | لا تدّعِ عنه |
|---:|---|---|---|
| 1 | **FazerCards** | المورد التقني الأول للشحن الآلي؛ API وwebhooks وتكامل المشروع جاهز. | أنه مثبت كمورد SGC أو كل السوق السوري. |
| 2 | **WDGZone** | بديل ومقارنة سعرية لكل SKU/منطقة؛ قد يتفوق في بعض باقات PUBG. | أنه المزود الخلفي للمواقع السورية. |
| 3 | **MaxStore** | أول خيار محلي إن كان احتياجك الحقيقي API محلي + دفع سوري؛ افحصه بلا رصيد أولاً. | أنه الأرخص أو أن مصدره معروف. |
| 4 | **Dark Shot** | تواصل للحصول على عرض reseller ووثائق رسمية فقط. | أن فئة `Test API` تعني API جاهزاً. |
| — | SGC GAME وS7SH وGameStoreSY | مراقبة سعر البيع المحلي وتجربة العميل. | أنهم موردو B2B أو أن أحدهم مصدر مخزون الآخر. |

### الخلاصة التنفيذية

- **لا تتوسط فوق متجر سوري آخر.** ستدفع هامشه ثم تضيف هامشك، فتخسر المنافسة السعرية.
- **ابقَ على FazerCards مباشرةً** للمسار الآلي الحالي، وقارن WDGZone لكل SKU قبل نقل أي لعبة.
- **اختبر MaxStore فقط** إذا كان يوفر قيمة محلية لا يقدمها المورد المباشر: دفع/تسوية محلية، كتالوج سوري مميز، أو دعم فعلي لاسترجاع الطلبات. الاختبار يبدأ بقراءة الكتالوج والوثائق، لا بإيداع أو طلب مدفوع.
- لا تطلب كلمة مرور لاعب أو رمز 2FA؛ المورد المقبول للشحن المباشر يطلب UID/Player ID وZone/Server فقط عند الحاجة.

## 5) حدود هذا الاستنتاج

1. أسعار الشحن والمخزون والخطط تتغير؛ هذه لقطة بتاريخ الرصد وليست عقد أسعار.
2. تشابه اسم المنتج أو سعره لا يثبت المورد، خصوصاً مع المنتجات ذات المناطق المختلفة.
3. حتى وإن تطابقت البصمة مع FazerCards، فلا يمكن معرفة هل SGC عميل مباشر أم عميل لمورد مشترك من صفحات عامة فقط.
4. واجهات الدفع المحلية مثل شام كاش هي **بوابات دفع**؛ ليست مورداً لشحن الألعاب بحد ذاتها.
5. لا يوجد في هذا الرصد شراء، تمويل، أو طلب مفاتيح API أو بيانات دخول.
