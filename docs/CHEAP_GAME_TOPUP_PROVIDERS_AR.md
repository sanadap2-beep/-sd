# أرخص مزوّدي شحن الألعاب القابلين للربط بالبوت

> الهدف نلاقي مزوّدي **جملة / API** لشحن ألعاب (PUBG UC، Mobile Legends، Free Fire،
> ألعاب أخرى) يكون سعرهم منخفض لدرجة إنك تقدر تحط هامش ربح من غير ما يصير سعرك
> غالي أمام الزبون.

---

## 1. ملاحظة مهمة أولاً (حتى لا تضيع)

- **سعر «الموقع للزبون» ليس سعر الجملة.** المواقع الكبيرة (SEAGM / BitTopup / G2G /
  EnjoyGM) أسعارها للعميل النهائي، ولو ربطتها بتكلفتها ما يبقى لك هامش.
  من الحساب: موقع مثل EnjoyGM بيبيع 60 UC بـ **$0.89** تقريباً [1](https://www.enjoygm.com/top-up/pubg-mobile)،
  وSEAGM بنفس الباقة بـ **$0.91** [2](https://www.seagm.com/en-us/pubg-mobile-uc-top-up-global).
  عشان تربح، لازم تاخد **سعر جملة/مزود API** أقل من هيك.
- **الأرخص فعلياً يتغير يومياً حسب المنطقة والخدمة.** لذلك التوصية هنا «قائمة مرشّحين
  + طريقة قياس» وليست أرقام نهائية. جرب كل مزوّد بمبلغ صغير قبل ما تحط رصيد كبير.
- **لا نربط موقع تجزئة بدون API.** أي مزوّد لازم يوفّر API لـ: جلب الخدمات، إنشاء طلب،
  فحص الحالة — وإلا البوت ما يقدر يسلّم تلقائياً.

---

## 2. خلاصة عملية (أسرع 5 خطوات)

1. ابدأ بـ **مزوّد SMM V2** من القائمة (سهل الربط من «🔌 مزودو المتجر» → SMM V2) —
   غالباً عنده فئة «Games / PUBG / Mobile Legends / Free Fire».
2. اسحب خدماته، وقارن سعر **كل وحدة** قبل ما تنشر.
3. الألعاب سوقها حساس للغاية بالسعر. ابدأ بهامش **5% – 15%**، وأنتظر أسبوع.
   هامش 50% الافتراضي للمتجر **غير مناسب لشحن الألعاب**.
4. لو عطالك مزوّد سعر أرخص لبنود معينة، فعّل **سحب من أكثر من مزوّد** وخلّ المتجر
   يعرض الأرخص لكل خدمة (البنية موجودة في المشروع).
5. فعّل **فئة الألعاب كنوع مستقل** `🎮 مزود ألعاب` بدل خلطها مع الرشق، عشان تبقى
   شاشة الشراء (Player ID / Zone ID) صحيحة.

## 3. القائمة المرشّحة (مرتّبة حسب الصعوبة/الفائدة)

### 🥇 1) FameGrows — أسهل وأشمل (شحن ألعاب + رشق)
- **المميز:** مزوّد SMM شامل فيه بوضوح شحن ألعاب: PUBG UC، Mobile Legends Diamonds،
  Free Fire Diamonds، إضافة لبقية خدمات الرشق [3](https://famegrows.com/).
- **السعر المعلن:** خدمات تبدأ من **$0.001** لكل ألف [3](https://famegrows.com/)،
  والكمية الفعلية للعبة تُفحص بعد السحب.
- **الربط:** سهل — بروتوكول **SMM V2** (الأمر `services` / `add` / `status`) + API Key.
  يُضم من «🔌 مزودو المتجر» → مزود جديد → SMM V2.
- **التوصية:** ابدأ به لأنه يغطي العاب + سوشيال ببنية API واحدة.

### 🥈 2) SocialPanel.io — عدد خدمات ضخم + API جاهز للـ White Label
- **المميز:** أكثر من **4,300 خدمة**، API للـ resellers (وكأنك تدير منصة بيضاء) [4](https://richmond.com/exclusive/article_a6038275-8473-5daa-ba81-b7677133753d.html).
- **السعر المعلن:** خدمات تبدأ من **$0.04 لكل 1000** [4](https://richmond.com/exclusive/article_a6038275-8473-5daa-ba81-b7677133753d.html) — العمق في الألعاب يظهر بعد السحب.
- **الربط:** SMM V2/API key.

### 🥉 3) Peakerr / Peaker — مزوّد Reseller قوي وبسعر جيد
- **المميز:** أكثر من **3,200 خدمة + 290 ألف عميل**، وAPI مخصص للوكلا
  [5](https://richmond.com/exclusive/article_a6038275-8473-5daa-ba81-b7677133753d.html)
  و[6](https://opsmatters.com/posts/top-7-smm-panels-api-access-resellers).
- **الربط:** SMM V2/API key. مفيد كخيار ثانٍ للمقارنة الحيّة بين مزوّدين.

### 🎮 4) VIPayment — مخصّص لألعاب (السوق الإندونيسي/آسيا الأرخص)
- **المميز:** API مخصص للألعاب: `Mobile Legends`, `Free Fire`, `PUBG`, مع فحص
  المخزون وأرصدة اللاعب (User ID + Zone ID) [7](https://vip-reseller.co.id/page/api/game-feature).
- **السعر:** أرخص منطقه في كثير من الألعاب الشائعة، لكن عملته/حدوده محلية.
- **الربط:** يُضاف بمزود مخصص `Custom JSON` (POST `https://vip-reseller.co.id/api/game-feature`).
  **تنبيه:** التوثيق `MD5(API_ID + API_KEY)`، وقسم «مزود مخصص» الحالي يدعم
  Bearer/Header/Query لكنه **لا يوقع MD5/HMAC** — لذلك يحتاج تعديل بسيط أو كلاس
  مخصص `vipayment.py` في `providers/` (أنصح به، بنفس نمط `herosms.py`).

### 🎮 5) MooGold — تغطية ألعاب عالمية + API شراكة
- **المميز:** متخصص شحن ألعاب عالمياً: PUBG من **$0.93**، Mobile Legends من **$0.09**
  في أسعار التجزئة [8](https://moogold.com/product/pubg-mobile/)
  [9](https://moogold.com/product/mobile-legends/) — وله API شراكة (user/partner/secret)
  [10](https://github.com/Medboubazine/MooGold).
- **الربط:** يحتاج مفتاح `user_id + partner_id + secret_key`؛ غالباً يحتاج ادائه
  HMAC/توقيع، فلا يربط بدون **مزوّد مخصص بسيط**. ممتاز بعد FameGrows لو الألعاب
  هي الأساس.

### (إضافي — جودة عالية لكن شراكة) UniPin و CodeGames
- **UniPin:** يوفر API شريك رسمي لـ «Top Up V2»: جلب قائمة الألعاب، تفاصيل الفئات،
  تحقق من اللاعب، إنشاء طلب، وفحص الحالة — توثيق شركاء واضح
  [11](https://documenter.getpostman.com/view/8087848/SVfNvUt2).
  **ملاحظة:** التشريع `hash_hmac(sha256, ...)` يحتاج مزوّد مخصص.
- **CodeGames:** كتالوج ضخم (أكثر من 20,000 لعبة/خدمة) مع API شركاء ويعيد الحقل
  المطلوب من المستخدم (`gameUserId` مثلاً) [12](https://github.com/codegamesgg/API-HUB).
  مناسب جداً إن صار صافي عملك كبير، أو لإضافة سلاسل متعددة بـ API واحد.

## 4. جدول مقارنة الربط

| المزوّد | البروتوكول في البوت | نوع التوثيق | صعوبة الربط | مناسب لـ |
|---|---|---|---|---|
| FameGrows | SMM V2 ✅ | API Key | سهلة جداً | البدء السريع + ألعاب + رشق |
| SocialPanel.io | SMM V2 ✅ | API Key | سهلة | كتالوج ضخم وبديل |
| Peakerr | SMM V2 ✅ | API Key | سهلة | مقارنة أسعار/مزوّد ثاني |
| VIPayment | Games JSON / Custom | MD5 sign ⚠️ | متوسطة (مطلوب كلاس توقيع) | ألعاب آسيا الأرخص |
| MooGold | Games JSON / Custom | user+partner+secret ⚠️ | متوسطة | ألعاب عالمية |
| UniPin | Games JSON / Custom | HMAC ⚠️ | متوسطة–عالية | شراكة رسمية |
| CodeGames | Custom JSON | API Key (يُتحقق) | متوسطة | كتالوج واسع لاحقاً |

> ❌ لا ننصح بالربط مع SEAGM / G2G / BitTopup / EnjoyGM كـ مزود أساسي: أسعارها
> للمستهلك (لا يبقى هامش)، وليس عندها واجهة بيع جملة مفتوحة بالشكل المناسب للبوت.

## 5. مقياس قبل أي إطلاق (Checklist)

- [ ] سحبت الخدمات ورأيت 3 باقات ألعاب على الأقل لكل لعبة شائعة.
- [ ] قارنت سعر التكلفة **بالوحدة** وليس بالـ1000 (ألعاب غالباً باقة ثابتة).
- [ ] جرّبت طلب اختباري واحد من حساب ثاني وقارنت **الوقت الفعلي** للتسليم.
- [ ] أوقفت أي خدمات المزود «نسخ/ربط يدوي» لأنها غير مناسبة للتسليم التلقائي.
- [ ] فعّلت استعلام `status` بعد بضع ثوانٍ بالنسبة للألعاب (الشحن قد يأخد 1–5 دقايق).
- [ ] ضبطت هامش ألعاب على 5–15%، وليس الهامش العام 50%.
- [ ] إذا طلبات الألعاب صارت حجر الزاوية، فصلناها في `providers/games_panel.py`
    مخصص (يوقّع MD5/HMAC) بدل الاعتماد على Custom JSON فقط.

---

## 6. خطوة تالية مقترحة (تحتاج موافقتك)

أقدر أجهّز **مزوّد مخصص `games_panel.py`** يوقّع MD5/HMAC (يدعم VIPayment و MooGold
و UniPin) ويُسحب تلقائياً ويُرتب المنتجات حسب الأرخص — نفس طريقة `SMM V2` لكن للعبة.
لو أنت موافق، يبدأ التنفيذ في المرحلة القادمة.
